# 🎮 Tic-Tac-Toe Game
Play Tic-Tac-Toe in your browser!

## ⭐️ Features
- Interactive Tic-Tac-Toe game
- Changeable names and avatars

## 💻 Technologies
- `HTML`
- `CSS`
- `JavaScript`

## 💫 Process
First, I inplemented the game functionality, trying to reduce the use of global variables and use modular design patterns to write cleaner code.
I went with a nostalgic school-inspired aesthetic for styling, and added the functionality to change the user's name and profile pictures.
